# Калькулятор

Простой графический калькулятор, разработанный на Python с использованием библиотеки Tkinter.

## Возможности

- сложение;
- вычитание;
- умножение;
- деление;
- работа с десятичными числами;
- очистка поля;
- обработка деления на ноль.

## Требования

Для запуска программы необходим Python 3.

Tkinter используется для создания графического интерфейса.

## Запуск программы

Для запуска необходимо выполнить команду:

```bash
python calculator.py
После запуска откроется окно калькулятора.

Управление

Для ввода чисел и математических операций используются кнопки
графического интерфейса.

Кнопка = выполняет вычисление.

Кнопка C очищает поле ввода.
