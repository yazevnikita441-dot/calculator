ТЕХНИЧЕСКОЕ ЗАДАНИЕ
Программный продукт «Калькулятор»

1. Введение

Данный документ содержит требования к программному продукту «Калькулятор».

Программный продукт предназначен для выполнения основных арифметических операций с использованием графического интерфейса.

Программа разрабатывается на языке программирования Python с использованием библиотеки Tkinter.

2. Основание для разработки

Основанием для разработки программного продукта является практическая работа по тестированию программного продукта методом «чёрного ящика».

Программа разрабатывается для последующего проведения функционального тестирования и выявления ошибок.

3. Назначение программы

Программа предназначена для выполнения следующих арифметических операций:

- сложение;
- вычитание;
- умножение;
- деление.

Программа должна предоставлять пользователю простой графический интерфейс для ввода чисел и выполнения операций.

4. Требования к программе

4.1. Функциональные требования

Программа должна:

1. Отображать графическое окно калькулятора.
2. Предоставлять кнопки для ввода цифр от 0 до 9.
3. Предоставлять кнопку для ввода десятичной точки.
4. Предоставлять кнопки арифметических операций:
   +;
   -;
   *;
   /.
5. Предоставлять кнопку = для получения результата.
6. Предоставлять кнопку C для очистки поля.
7. Выполнять арифметические вычисления.
8. Отображать результат вычисления.
9. Обрабатывать попытку деления на ноль и выводить сообщение об ошибке.

4.2. Требования к надёжности

Программа не должна завершаться аварийно при выполнении предусмотренных пользователем операций.

При делении на ноль программа должна вывести сообщение:

«Ошибка: деление на 0»

При некорректном выражении программа должна вывести сообщение об ошибке.

4.3. Условия эксплуатации

Для работы программы необходим компьютер с установленным Python 3.

Для запуска программы необходимо наличие файла calculator.py.

Программа предназначена для работы в операционной системе, поддерживающей Python 3 и библиотеку Tkinter.

4.4. Требования к совместимости

Программа должна запускаться в среде Python 3.

Для работы графического интерфейса используется библиотека Tkinter.

5. Требования к интерфейсу

Графический интерфейс должен содержать:

- поле отображения введённых данных и результатов;
- кнопки цифр от 0 до 9;
- кнопку десятичной точки;
- кнопки арифметических операций;
- кнопку =;
- кнопку C.

Окно программы должно иметь название:

«Калькулятор»

Интерфейс должен быть понятным и удобным для пользователя.

6. Требования к приёмке

Программа считается соответствующей требованиям, если:

1. Программа запускается без критических ошибок.
2. Все кнопки интерфейса доступны пользователю.
3. Сложение выполняется корректно.
4. Вычитание выполняется корректно.
5. Умножение выполняется корректно.
6. Деление выполняется корректно.
7. Очистка поля работает корректно.
8. Деление на ноль обрабатывается с выводом сообщения об ошибке.
9. Результат вычисления отображается в поле программы.

7. Требования к документации и запуску

В состав проекта входят:

- файл программы calculator.py;
- файл README.md;
- техническое задание docs/TZ.md.

Для запуска программы необходимо:

1. Открыть терминал.
2. Перейти в папку проекта.
3. Выполнить команду:

python calculator.py

После запуска должно открыться окно программы «Калькулятор».

8. Порядок контроля и приёмки

Проверка программного продукта выполняется путём функционального тестирования методом «чёрного ящика».

В ходе тестирования проверяются:

- ввод чисел;
- выполнение арифметических операций;
- получение результата;
- очистка поля;
- обработка деления на ноль;
- реакция программы на некорректный ввод.

Фактический результат работы программы сравнивается с ожидаемым результатом, указанным в требованиях.

Обнаруженные несоответствия фиксируются в документации по результатам тестирования.

9. Этапы разработки

Разработка программного продукта включает следующие этапы:

1. Создание базовой версии калькулятора.
2. Разработка графического интерфейса.
3. Реализация арифметических операций.
4. Проверка работоспособности программы.
5. Подготовка технической документации.
6. Подготовка версии программы для тестирования.
7. Проведение тестирования методом «чёрного ящика».
8. Документирование обнаруженных ошибок.
